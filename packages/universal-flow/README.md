# Universal Flow

Universal Flow is the orchestration package for turning project requirements into
technical specs, Ponytail-reviewed packets, parallel implementation worktrees, and
targeted recovery.

- Repository: https://github.com/jmarlett93/universal-flow
- Pinned ref: `c3e37bd`
- Install location: `$UNIVERSAL_FLOW_HOME` or `$HOME/tools/universal-flow`
- Cursor integration: `~/.cursor/plugins/local/universal-flow`
- Recommended preset: `cursor.simple`

It is installed by default with the lore installer:

```bash
./install.sh /path/to/repo
```

Use `--without-universal-flow` to skip it.

An existing Universal Flow checkout or Cursor plugin link is left unchanged. Update
those separately with the repository's normal Git workflow.
