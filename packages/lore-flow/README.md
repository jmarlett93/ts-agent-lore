# Lore Flow

Lore Flow is the orchestration package for turning project requirements into
technical specs, Ponytail-reviewed packets, parallel implementation worktrees, and
targeted recovery.

- Repository: https://github.com/jmarlett93/lore-flow
- Pinned ref: `82abc3a`
- Install location: `$LORE_FLOW_HOME` or `$HOME/tools/lore-flow`
- Cursor integration: `~/.cursor/plugins/local/lore-flow`
- Recommended preset: `cursor.simple`

It is installed by default with the lore installer:

```bash
./install.sh /path/to/repo
```

Use `--without-lore-flow` to skip it.

An existing Lore Flow checkout or Cursor plugin link is left unchanged. Update
those separately with the repository's normal Git workflow.
